# PANDRA Duel — unduh game untuk HP Android

**Unduh di sini:** https://github.com/Paimo999/pandra-apk/releases/latest/download/PANDRA-Duel.apk

## Cara memasang (bantu anak, ±2 menit)
1. Buka link di atas dari HP Android, tunggu unduhan selesai (±146 MB, sebaiknya pakai Wi-Fi).
2. Ketuk file **PANDRA-Duel.apk** yang sudah terunduh.
3. Kalau muncul peringatan *"aplikasi dari sumber tidak dikenal"* → ketuk **Setelan** → nyalakan **Izinkan dari sumber ini** → kembali → **Pasang**.
   (Game belum ada di Play Store, jadi HP selalu bertanya. Setelah terpasang, izin ini boleh dimatikan lagi.)
4. Kalau Play Protect bertanya → **Tetap pasang**.
5. Buka **PANDRA Duel**. Game memperbarui dirinya sendiri lewat internet — tidak perlu mengunduh ulang.

Hanya untuk HP Android (bukan iPhone).
